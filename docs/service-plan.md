## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | AXISOLVE Writing Engine |
| 한 줄 정의 | 주제를 고르거나 직접 적으면, 학년 합격 기준을 통과할 때까지 AI 가 다시 쓰는 영어 라이팅 트레이닝 서비스 |
| 목적 | 초등 영어 라이팅에서 "학년 기준에 맞는 모범 답안"을 만드는 데 드는 강사의 시간을 없앤다 |
| 1차 타겟 | 초등 영어 라이팅을 지도하는 학원 강사 — 수업 자료를 매주 직접 쓰는 사람 |
| 2차 타겟 | 어학원 레벨테스트를 준비하는 초등 3~6학년 학습자와 그 학부모 |
| 배포 형태 | 정적 프론트엔드 + Python 서버리스 함수 5개 (Vercel) |

### 이 서비스가 지키는 선

생성물을 학생이 자기 글로 제출하는 것은 이용약관에서 금지합니다([terms.html](../terms.html)).
이 서비스가 파는 것은 **답안**이 아니라 **기준을 통과한 예시와 그것을 따라 쓰는 워크북**입니다.
그래서 결과 화면에는 언제나 모범 에세이와 함께 브레인스토밍·아웃라인·어휘가 같이 나오고,
PDF 에는 학생이 직접 쓰는 빈 연습장과 자가진단표가 들어갑니다.

## 2. 문제 정의

초등 영어 라이팅 수업에서 강사가 겪는 병목은 "주제"가 아니라 **"학년 기준에 맞는 모범 답안"** 입니다.

1. 실전 주제는 학원마다 이미 축적되어 있습니다. 이 서비스도 기출 165개를 갖고 시작합니다.
2. 일반 AI 챗봇에 주제를 넣으면 글은 나옵니다. 그런데 **분량과 문단 구조가 학년 기준과 어긋납니다.**
   초1-2 에게 200단어 4문단이 나오거나, 초5-6 에게 축약형이 섞인 구어체 글이 나옵니다.
3. 결과를 사람이 단어를 세어 보고 다시 요청해야 하므로, 결국 시간이 절약되지 않습니다.
4. 레벨테스트 채점은 이 기준으로 떨어뜨립니다. 내용이 좋아도 분량 미달이면 탈락입니다.

## 3. 해결 방식 — "생성"이 아니라 "기준 통과까지 생성"

1. 학년별 합격 기준을 코드에 상수로 고정합니다 (`app.js` 의 `RUBRIC`).
2. AI 응답을 받은 즉시 브라우저가 단어 수·문장 수·문단 수·축약형을 **기계적으로** 검사합니다.
3. 미달 항목을 문장으로 만들어 프롬프트에 되먹이고, **최대 4회까지 자동으로 다시 씁니다.**
4. 4회 모두 미달이면 그중 가장 근접한 결과를 보여 주고 **경고 배지를 붙입니다.**
   조용히 실패하지 않습니다.

자동 재시도는 크레딧을 추가로 차감하지 않습니다. 4회를 호출해도 1크레딧입니다.
사용자가 잘못한 것이 아니라 기계가 기준을 못 맞춘 것이기 때문입니다.

### 학년별 합격 기준

| 학년 그룹 | 분량 | 구조 | 문법·격식 |
|---|---|---|---|
| Grade 1-2 (초1-2) | 60~80단어 / 5~7문장 | 한 문단 | 단문 위주, 축약형 허용 |
| Grade 3-4 (초3-4) | 100~130단어 | 한 문단 (Topic → Support → Closing) | 단문·복문 혼합 |
| Grade 5-6 (초5-6) | 180~220단어 | 정확히 4문단 (Intro / Body 1 / Body 2 / Conclusion) | 포멀, 축약형 금지 |

## 4. 페이지·섹션 구성 (4개 + 법적 고지 3개)

한 문서 안에서 `location.hash` 로 섹션을 갈아 끼웁니다([nav.js](../nav.js)).
상단 네비게이션 링크와 각 섹션의 CTA 버튼이 모두 같은 해시를 가리키므로,
뒤로 가기 버튼도 그대로 동작하고 각 섹션의 주소를 그대로 공유할 수 있습니다.

| 해시 | 섹션 | 목적 | 주요 요소 |
|---|---|---|---|
| `#home` | 소개 (랜딩) | 왜 필요한지 납득시킨다 | 히어로 · 4대 채점 루브릭 · 학년별 기준표 · 과외 비용 비교 · 5문항 자가진단 · 해결 흐름 · CTA |
| `#generator` | 에세이 생성 | **핵심 기능** | 주제 사이드바(검색·직접 입력) · 학년 탭 3종 · 생성 버튼 · 결과 패널 · 워크북 PDF |
| `#pricing` | 요금제 | 결제 경로를 연다 | 상품 4종 · 충전 코드 등록 폼 |
| `#about` | 사용법·FAQ | 진입 장벽을 없앤다 | 4단계 사용법 · FAQ 10문항 |

| 별도 문서 | 용도 |
|---|---|
| [privacy.html](../privacy.html) | 개인정보 처리방침 |
| [terms.html](../terms.html) | 이용약관 (생성물 제출 금지 조항 포함) |
| [refund.html](../refund.html) | 환불 규정 |

### 네비게이션 방식

- 상단 고정 헤더의 링크 4개 (`data-nav` 속성) — 현재 섹션에 `aria-current="page"` 가 붙습니다.
- 섹션이 바뀌면 스크롤을 맨 위로 되돌립니다. 긴 랜딩에서 넘어왔을 때 중간부터 보이지 않게 하기 위함입니다.
- 알 수 없는 해시는 `#home` 으로 떨어집니다.

## 5. AI 기능 설계

### 5.1 흐름

```
[사용자]  주제 선택(기출 165개) 또는 직접 입력 + 학년 선택 + 아이디어(선택)
   │
   ▼
[브라우저 app.js] 학년별 프롬프트 조립 (분량 규칙 + 출력 JSON 스키마)
   │  POST /api/generate  { prompt, system, gen_id, topic_no, grade }
   ▼
[서버 api/generate.py]  출처 검증 → 레이트리밋 → 크레딧 차감 → OpenAI Responses API 호출
   │                     (OPENAI_API_KEY 는 이 함수 안에만 존재)
   ▼
[브라우저] JSON 추출 → 학년 기준 검증 → 미달이면 부족한 항목을 프롬프트에 붙여 재요청
   │                                        (최대 4회, 크레딧 추가 차감 없음)
   ▼
[화면]  브레인스토밍 질문 · 아웃라인 · 어휘/문형 · 에세이 본문 + 단어수 게이지
   │
   ▼
[선택]  POST /api/pdf  →  학년별 3~4페이지 A4 워크북 내려받기
```

### 5.2 입력

| 항목 | 필수 | 형식 | 비고 |
|---|---|---|---|
| 주제 | ✅ | 기출 165개 중 택1, **또는** 2자 이상 직접 입력 | 직접 입력은 한글로 적어도 영어 에세이가 나옵니다 |
| 학년 | ✅ | Grade 1-2 / Grade 3-4 / Grade 5-6 | 탭으로 선택, 학년마다 따로 생성 |
| 아이디어 | ❌ | 최대 1,000자 | 비우면 AI 가 소재를 직접 고릅니다 |

### 5.3 출력

한 번의 생성으로 네 덩어리가 함께 나옵니다. 에세이만 주면 베껴 쓰기가 되기 때문입니다.

| 블록 | 내용 |
|---|---|
| 브레인스토밍 | 학생이 스스로 답해 볼 질문 |
| 아웃라인 | 문단별 역할과 넣을 내용 |
| 어휘·문형 | 이 주제에 쓸 표현 목록 |
| 모델 에세이 | 학년 기준을 통과한 본문 + 단어 수 게이지 |

### 5.4 실패 처리 — 과제 요구 3종을 모두 구현

| 구분 | 상황 | 사용자에게 보이는 것 | 구현 위치 |
|---|---|---|---|
| **빈 입력** | 주제를 고르지 않고 생성 | 생성 버튼 비활성 + "왼쪽 목록에서 주제를 선택하십시오" | `app.js` |
| **빈 입력** | 직접 입력 주제가 2자 미만 | 폼 아래 빨간 글씨 "주제를 입력해 주십시오." + 입력칸으로 포커스 이동 | `app.js` `submitCustomForm` |
| **빈 입력** | 서버에 빈 프롬프트가 도달 | HTTP 400 "생성 요청이 비어 있습니다." | `api/generate.py` |
| **API 오류** | 키 미설정 | HTTP 500 "OPENAI_API_KEY 가 설정되지 않았습니다" | `api/generate.py` |
| **API 오류** | 호출량 초과 | HTTP 429 "요청이 몰려 잠시 처리할 수 없습니다" + `Retry-After` | `api/_guard.py` |
| **API 오류** | 로그인 필요 / 크레딧 부족 | HTTP 401 · 402 → 안내창을 띄우고 오류 문구는 숨김 | `app.js` `billingError` |
| **API 오류** | 응답이 JSON 이 아님 | "응답에서 JSON을 찾을 수 없음" → 자동 재시도 대상 | `app.js` `callModel` |
| **지연/타임아웃** | 20초 경과 | "응답이 평소보다 오래 걸리고 있습니다. 창을 닫지 말고 기다려 주십시오." | `app.js` `SLOW_NOTICE_MS` |
| **지연/타임아웃** | 75초 경과 | 요청을 끊고 "응답이 75초를 넘겨 중단했습니다. 잠시 후 다시 시도해 주십시오." | `app.js` `REQUEST_TIMEOUT_MS` |
| **지연/타임아웃** | 서버에 아예 닿지 못함 | "AI 서버에 연결하지 못했습니다. 인터넷 연결을 확인한 뒤 다시 시도해 주십시오." | `app.js` `callModel` |
| **품질** | 4회 재시도 후에도 미달 | 최근접 결과 + 부족 항목을 적은 경고 배지 | `app.js` `generateWithRetry` |

> 75초는 서버 함수 상한(`vercel.json` 의 `maxDuration` 60초)보다 길게 잡았습니다.
> 서버가 자기 판단으로 끝낼 기회를 먼저 주고, 그래도 아무 말이 없을 때 브라우저가 끊습니다.
> 반대로 잡으면 서버는 정상 처리 중인데 브라우저만 포기하는 일이 생깁니다.

### 5.5 사용자에게 주는 가치

강사 기준으로 주제 하나·학년 하나의 모범 답안을 직접 쓰면 20~30분이 듭니다.
이 서비스는 같은 것을 **한 번의 클릭과 1크레딧**으로 내놓고, 분량 미달을 사람이 세지 않아도
기계가 잡아 줍니다. 결과는 그대로 인쇄 가능한 워크북이 되므로 별도 편집 시간도 들지 않습니다.

## 6. 기술 스택

| 계층 | 선택 | 사유 |
|---|---|---|
| 프론트엔드 | 바닐라 HTML / CSS / JavaScript | 빌드 단계가 없어 정적 호스팅에 그대로 올라갑니다. 프레임워크 금지 조건과도 맞습니다 |
| 라우팅 | `location.hash` + 클래스 토글 | 페이지 4개를 위해 라우터 라이브러리를 넣을 이유가 없습니다 |
| 백엔드 | Vercel Python Serverless Functions | 상시 서버가 필요 없고, 요청이 없으면 비용이 0 입니다 |
| AI | OpenAI Responses API | 긴 지시문과 JSON 스키마 준수에 적합합니다 |
| PDF | reportlab (서버 렌더링) | 출제 학원명을 브라우저로 내려보내지 않고 헤더에 찍기 위함입니다 |
| 계정·크레딧 | Supabase (카카오 로그인) | 환경변수 미설정 시 계층 전체가 자동으로 꺼집니다 |
| 임시 저장 | 브라우저 localStorage | 새로고침해도 초안이 남습니다 |

## 7. 보안·비용 방어

**API 키** — `OPENAI_API_KEY` 는 Vercel 환경변수에만 존재합니다. 브라우저는 같은 도메인의
`/api/generate` 만 호출하며, 프론트엔드 코드·네트워크 응답·저장소 어디에도 키가 없습니다.

**비용** — 생성 버튼 한 번이 최대 4회의 유료 호출이 될 수 있습니다. 세 겹으로 막습니다.

| 계층 | 초과 시 | 기본 상한 |
|---|---|---|
| 출처 검증 (`ALLOWED_ORIGINS`) | 403 | 미설정 시 검사 안 함 |
| IP 시간당 | 429 + `Retry-After` | 12회 |
| IP 일일 | 429 + `Retry-After` | 30회 |
| 전역 일일 | 503 | 500회 |

IP 는 `IP_SALT` 를 섞은 SHA-256 해시로만 보관하고 원문은 저장하지 않습니다.
카운터가 함수 인스턴스 메모리에 있으므로 정확한 과금 장치가 아니라 **폭주 차단 장치**입니다.
최종 방어선은 OpenAI 계정의 Budget limit 이며 반드시 함께 설정해야 합니다.

**주제 DB** — 165개 주제와 출제 학원명은 자산이므로 `topics.json` 을 배포에서 제외하고,
학원명을 제거한 사본(`api/_topics.py`)만 `/api/topics` 를 통해 내려보냅니다.
