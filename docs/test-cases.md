# 테스트 케이스와 실행 기록

과제 8절 "AI 기능 테스트 입력/결과 예시" 에 대응하는 문서입니다.
**실제로 돌려 본 것과 아직 안 돌려 본 것을 섞지 않았습니다.** 상태 칸을 보십시오.

| 표기 | 뜻 |
|---|---|
| ✅ 확인 | 아래 "실행 환경" 에서 직접 실행하고 응답을 그대로 옮겼습니다 |
| 🖐 수동 | 브라우저에서 눈으로 확인해야 하는 항목입니다 (증빙은 `docs/evidence/`) |
| 🔑 키 필요 | 유효한 `OPENAI_API_KEY` 가 있어야 확인됩니다 |

### 실행 환경

```
py dev_server.py            # PORT=3124 로 기동
Python 3.14.5 / Windows 11
OPENAI_API_KEY 미설정 상태  # 키 없이도 확인되는 경로를 먼저 전부 확인
```

## A. AI 기능 — 정상 입력

| # | 입력 | 기대 결과 | 상태 |

| A-2 | 직접 입력 "내가 좋아하는 계절" / Grade 3-4 | 한글 주제인데 **영어 에세이**가 나오고, 100~130단어 | 🔑 키 필요 |
| A-3 | 기출 40번 / Grade 5-6 / 아이디어 200자 | 정확히 4문단, 180~220단어, 축약형 없음 | 🔑 키 필요 |

## B. AI 기능 — 빈 입력 / 잘못된 입력

| # | 입력 | 기대 결과 | 실제 | 상태 |
|---|---|---|---|---|
| B-1 | 주제를 고르지 않고 생성 시도 | 생성 버튼이 비활성이고 안내 문구가 보인다 | 버튼 비활성 | 🖐 수동 |
| B-2 | 직접 입력 주제에 1자만 입력 후 제출 | "주제를 입력해 주십시오." + 입력칸 포커스 | 문구 표시 | 🖐 수동 |
| B-3 | 서버에 빈 프롬프트 전송 | HTTP 400 + 안내 문구 | `400` `{"error": "생성 요청이 비어 있습니다. 주제를 선택한 뒤 다시 시도해 주십시오."}` | ✅ 확인 |
| B-4 | 20,001자 프롬프트 전송 | HTTP 400 + 줄이라는 안내 | `400` `{"error": "요청이 너무 깁니다. 키워드를 줄인 뒤 다시 시도해 주십시오."}` | ✅ 확인 |
| B-5 | JSON 이 아닌 본문 전송 | HTTP 400 + 형식 오류 안내 | `400` `{"error": "요청 형식이 올바르지 않습니다. (JSON 파싱 실패)"}` | ✅ 확인 |

재현 명령:

```bash
curl -s -X POST http://localhost:3000/api/generate \
     -H "Content-Type: application/json" \
     -d '{"prompt":"","system":"t"}'
# {"error": "생성 요청이 비어 있습니다. 주제를 선택한 뒤 다시 시도해 주십시오."}
```

## C. AI 기능 — API 오류

| # | 조건 | 기대 결과 | 실제 | 상태 |
|---|---|---|---|---|
| C-1 | `OPENAI_API_KEY` 없이 생성 | HTTP 500 + 설정 방법 안내 | `500` `{"error": "OPENAI_API_KEY 가 설정되지 않았습니다. Vercel 프로젝트의 Settings > Environment Variables 에서 추가한 뒤 재배포해 주십시오."}` | ✅ 확인 |
| C-2 | IP 시간당 12회 초과 | HTTP 429 + `Retry-After` | — | 🖐 수동 |
| C-3 | 로그인 없이 무료 2회 소진 후 생성 | HTTP 401 → 오류 문구 대신 로그인 안내창 | — | 🔑 키 필요 |
| C-4 | 크레딧 0 인 계정으로 생성 | HTTP 402 → 충전 안내창 | — | 🔑 키 필요 |
| C-5 | 존재하지 않는 엔드포인트 호출 | HTTP 404 | `404` | ✅ 확인 |
| C-6 | `/api/topics` 에 POST | HTTP 405 | `405` `{"error": "GET 요청만 지원합니다."}` | ✅ 확인 |

## D. AI 기능 — 지연 / 타임아웃

| # | 조건 | 기대 결과 | 상태 |
|---|---|---|---|
| D-1 | 응답이 20초를 넘김 | 로딩 아래에 "응답이 평소보다 오래 걸리고 있습니다…" 표시, 요청은 계속 | 🖐 수동 |
| D-2 | 응답이 75초를 넘김 | 요청을 끊고 "응답이 75초를 넘겨 중단했습니다…" 표시, 버튼 다시 활성 | 🖐 수동 |
| D-3 | 서버에 닿지 못함 (오프라인) | "AI 서버에 연결하지 못했습니다. 인터넷 연결을 확인한 뒤 다시 시도해 주십시오." | 🖐 수동 |

D-3 재현 방법: 브라우저 개발자도구 → Network → Offline 으로 바꾸고 생성 버튼을 누릅니다.
D-1 재현 방법: 같은 화면에서 Network throttling 을 `Slow 3G` 로 두면 20초를 쉽게 넘깁니다.
