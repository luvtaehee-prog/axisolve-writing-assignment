이 서비스가 해결하는 문제

기준 미달 답안을 스스로 걸러냅니다

생성된 글의 단어 수, 문장 수, 문단 개수, 축약형 사용 여부를 브라우저가 즉시 검사합니다. 기준에 미달하면 부족한 항목을 프롬프트에 다시 적어 최대 4회까지 자동으로 다시 씁니다.

학년마다 다른 글을 씁니다

초1-2는 60~80단어 단문 위주, 초3-4는 100~130단어 한 문단 논리 구조, 초5-6은 180~220단어 4문단 아카데믹 에세이. 같은 주제라도 학년별로 다른 결과가 나옵니다.

API 키는 브라우저에 내려오지 않습니다

모든 AI 호출은 서버의 /api/generate 함수를 거칩니다. 키는 서버 환경변수에만 존재하므로 개발자 도구로도 확인할 수 없습니다.

사용법

  1. 주제를 고릅니다

    왼쪽 목록에서 영역(취향·상상·경험·자기소개·학교사회)을 펼치고 주제를 선택합니다. 번호, 영어 주제문, 출제 학원명으로 검색할 수도 있습니다.

  2. 학년과 키워드를 정합니다

    초1-2 / 초3-4 / 초5-6 중 필요한 학년 카드를 엽니다. 꼭 넣고 싶은 소재가 있다면 키워드 칸에 적습니다. 비워두면 AI가 주제에 맞는 소재를 직접 고릅니다.

  3. 생성 버튼을 누릅니다

    브레인스토밍 질문, 아웃라인, 어휘·문형, 에세이 본문이 함께 만들어집니다. 기준 미달 시 자동으로 다시 작성되므로 최대 1분 정도 걸릴 수 있습니다.

  4. 결과를 저장하거나 내보냅니다

    결과는 브라우저에 자동 저장되어 새로고침해도 남아 있습니다. JSON 내보내기로 교재 제작 파이프라인에 그대로 넣을 수 있습니다.

자주 묻는 질문

생성 결과가 매번 다른가요?

네. 같은 주제·같은 학년이라도 호출할 때마다 다른 글이 나옵니다. 마음에 드는 결과가 나올 때까지 다시 생성해도 됩니다.

"기준 미달" 경고가 뜨면 어떻게 하나요?

4회 재작성 후에도 단어 수나 문단 수가 맞지 않으면, 기준에 가장 가까운 결과를 보여주고 경고를 띄웁니다. 이때는 다시 생성하거나 키워드를 조금 더 구체적으로 적어 보십시오.

제 API 키가 노출될 위험은 없나요?

없습니다. 브라우저는 이 사이트의 /api/generate 만 호출하고, Anthropic API 호출은 서버 함수 안에서만 일어납니다. 키는 서버 환경변수에만 저장됩니다.

저장된 결과는 어디에 남나요?

사용 중인 브라우저의 localStorage에만 저장됩니다. 서버에는 아무것도 기록되지 않으므로 다른 기기나 다른 브라우저에서는 보이지 않습니다.

오류 메시지가 나옵니다.

화면에 표시되는 문구를 확인해 주십시오. "API 키가 설정되지 않았습니다"는 서버 환경변수 누락, "요청이 몰려…"는 호출량 초과, "연결하지 못했습니다"는 네트워크 문제입니다.
